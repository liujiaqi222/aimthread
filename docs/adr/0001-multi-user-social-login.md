# 独立个人账户与第三方登录

2026-10-18 确认：AimThread 从单实例单用户改为同一部署支持多个相互独立的个人账户。任何人均可通过 Google 或 GitHub 首次登录并自助创建账户；完成切换后只保留这两种登录方式，移除实例密码入口，本轮不引入团队或共享目标。

每个用户独立拥有 Goal、Task、Session、偏好与 AI 授权。Web 与 MCP 都必须携带真实用户身份并执行相同的所有权校验；设置、当前选择、未结束计时限制、并发锁和幂等记录均按用户隔离，不能只替换登录入口。

产品尚未上线，既有数据为无需保留的测试数据，因此不实现旧 owner 账户和业务数据的迁移或兼容。此决策不表示已执行数据库清理。账号关联见 ADR-0002；AI 连接保持可选，从 ChatGPT 发起连接时先完成 Google / GitHub 登录，再自动返回原授权页，经用户同意后仅访问其数据。本文记录已确认范围，功能尚未实现。

正式站点使用 `https://aimthread.com`，本地开发使用 `http://localhost:3000`。本轮真实第三方登录配置与验收覆盖这两个环境，不支持每个 Vercel Preview 地址登录；需要远程测试时再配置固定测试域名。

实施规格已发布为 [Issue #38](https://github.com/liujiaqi222/aimthread/issues/38)。
