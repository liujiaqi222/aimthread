# AimThread 产品 redesign

日期：2026-10-13

状态：用户已选择方向二，并要求重新设计全部色彩。开发基线见 [UI 规范](ui-system.md)，原访谈及两套提案保留为决策来源；实现与验证进展见 [开发验收记录](../validation/redesign.md)。未发布上线。

## 要解决的问题

用户已经在外部 AI 中把目标拆成了可以执行的任务。AimThread 承接这些任务，让用户选定工作、开始计时、留下执行记录，并通过统计看见实际投入与任务完成情况。

产品核心是 **AI 计划的执行与跟踪**。外部 MCP 已跑通是用户在本次访谈中确认的状态，本轮没有重新进行客户端联通验证。内置 AI 规划留待后续考虑。

## 已确认的关键约束

- 整体重构产品体验，视觉重新探索。
- 全局主导航采用左侧侧边栏，替代顶部 Tab。
- 首页突出当前工作，其他任务按需展开；目标选择直接从首页弹窗进入。
- 专注页以工作内容为主，始终清楚展示计时器，并显示 AI 写入的任务说明和资源。
- 保留正在计时时的站内离开限制，不恢复跨页面继续计时功能。
- 番茄每轮独立记录、在足迹独立展示；移除长休息，不自动开始休息。
- 结束反馈和接续提示沿用现有方式，不新增逐轮提示或强制复盘。
- 足迹统计优先，支持日、周、月、年查看分析；真实投入为主，任务完成情况为辅。
