# AimThread UI 规范 · 2026-10-13

状态：本轮开发基线。用户选择方向二，并要求完全重新设计色彩；不继承现有暖白、橙色、绿色，也不将提案中的青绿色当作指定色。

## 体验与场景

准备 → 深色专注 → 结束反馈 → 足迹。当前工作优先，时间始终清楚；只有正在执行时使用深色场景。任务说明、资源和笔记不可因场景切换隐藏。桌面左侧导航，专注时收窄为图标；移动端使用可关闭的导航抽屉。保留结束并保存后离开的保护。

## 全新色彩：Paper / Ink / Iris

以冷灰纸面、蓝黑墨色和鸢尾紫组成系统。紫色标识可操作的主路径，不表示任务优劣。所有颜色通过语义 token 使用。

状态以文字和图标同时表达，不能只依赖颜色。统计图使用紫、蓝、灰紫等稳定序列；目标颜色仅作为识别，不表示排名。提示、错误和成功均避免低对比浅色字。浅色正文目标 WCAG AA 4.5:1；大字及控件边界按 3:1 校验。

## 排版与布局

- 中文使用系统无衬线；标题 28–36px/1.3、当前任务 28–40px/1.35、正文 14–16px/1.7、辅助文字 12–13px/1.5。
- 时间使用等宽数字，移动端 56px 起，桌面 88px 起；不每秒通过 live region 朗读。
- 桌面侧栏展开 216px、收起 72px，专注时默认收起并允许手动展开。内容最大 1120px，工作内容最大 760px；移动端水平留白 20px。
- 间距采用 4px 基数：8、12、16、24、32、48。按钮高度至少 40px，主操作 48px，触摸目标至少 44px。
- 8px 控件圆角、12px 面板圆角、16px 弹窗圆角。优先留白与分隔线，只有输入、选择及独立信息需要容器。

## 组件契约

- 首页：目标名称打开目标弹窗；任务通过独立面板切换。主标题、说明、资源、匹配的接续提示在模式和开始按钮之前。准备阶段不显示巨大倒计时。其他任务按需展开。
- 专注：固定工作上下文，不展示不可用的切换表单。阶段、轮数、时间、暂停/继续、结束、过程记录清晰可达。正文和链接支持长文本换行。
- 选择与确认：有标题、关闭按钮、焦点管理、Escape、滚动边界；请求失败留在原上下文并允许重试。选择完成后返回当前工作。
- 足迹：日/周/月/年及前后周期切换 → 当前周期摘要 → 趋势与目标分布 → 独立轮记录。年按月汇总，点击月进入月、点击日进入日。日显示真实执行时间线。
- 表单：可见标签、就地错误、提交中状态；成功不丢失已选择上下文。设置、引导、登录、空白、加载和错误页使用相同 token。
- 动效 120–180ms，reduced-motion 下禁用非必要动画，不延迟操作。

## 行为映射与实施边界

沿用现有 Session 包含多轮的模型，Focus Round 对应 focus phase；暂停产生多个 Focus Interval，不能拆成多个轮。足迹逐轮展示但统计仍从真实区间聚合，次数明确写作执行次数。达到设定轮数沿用自动保存，结束卡仍只出现一次；不改变 MCP Session 身份。此项采用设计文档推荐的保守映射，不将用户仅选择视觉方向记为额外领域确认。

新建计时只使用专注、短休息和轮数；移除长休息的配置及新阶段生成。旧长休息阶段可读取，不修改已经发生的投入。休息和下一轮均由用户主动开始。

首次打开先识别已有目标；没有目标时提供外部 AI 连接和只填标题的手动路径，复制地址不代表计划已经写入。默认设置实际保存。时间线只展示实际投入，不扩展未来排程。

## 验证

逐项验证桌面与 375px：首次使用、选择目标/任务、开始、暂停、刷新恢复、到时等待、主动休息、下一轮、自动收尾、笔记、结束卡、离开保护、周期浏览、轮记录、补录更正、管理和设置。服务端/MCP 共用状态机和统计；不通过重复记录来实现轮展示。

### 侧边栏展开与收起

桌面侧边栏顶部提供展开／收起按钮。展开宽 216px，收起宽 72px；收起保留导航和退出图标，名称通过悬停提示与无障碍标签提供，正文同步扩展。切换用 200ms 过渡，减少动态效果设置下禁用。专注场景默认收起，用户可手动展开；手动选择在当前应用会话的路由切换期间保留。手机继续使用遮罩抽屉，不显示桌面图标栏。

收起操作提交时立即移除菜单文字；宽度过渡只作用于侧栏与正文。收起状态的顶部按钮默认显示 AimThread 品牌图标，悬停或键盘聚焦时立即替换成展开图标。
