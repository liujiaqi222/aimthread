# Redesign 实现与验证 · 2026-10-13

本轮先制定 [UI 规范](../design/ui-system.md)，再按用户选择的方向二实施。全新冷灰纸面、蓝黑专注场景与鸢尾紫主操作覆盖准备、执行、足迹、管理、设置、引导、账户与错误页面。

## 已实现

- 桌面左侧导航、专注时图标侧栏、移动端抽屉；保留未结束计时的离开保护，保存失败可重试。
- 首页突出当前工作，目标与任务分别通过弹窗选择，其他任务按需展开。准备状态使用紧凑计时设置，点击开始才显示大号计时器。
- 任务说明、HTTP(S) 资源、匹配的接续提示在执行及刷新恢复后保持可读。长说明可展开。正计时、番茄、暂停、阶段等待、笔记与打断沿用服务端状态机。
- 新配置移除长休息；Web 与 MCP 都只生成短休息。休息和下一轮由用户主动开始，达到设定轮数沿用自动保存和一次结束卡。
- 足迹提供日、周、月、年、前后周期、指定日期、趋势、目标分布及逐级下钻；MCP `stats_get` 同样支持自然年。
- 每个 Focus Round 独立展示；暂停仍属于原轮，点击进入所属 Session 详情。累计取整守恒，跨日裁剪不重复计时。补录／更正保留明确依据，不伪造专注区间。
- 足迹日视图与首页今日抽屉展示小时刻度的实际时间线。正计时与番茄都可显示，暂停、休息、等待留白，重叠投入并列。
- 首次手动路径只填目标标题即可开始；外部 AI 入口检查真实写入结果，保留已有目标的直接进入行为。设置直接提供番茄参数入口。
- PRD 已同步，未改变 Session 身份，无数据迁移、生产发布或实际 ChatGPT 客户端重新授权操作。

## 验证口径

单元测试覆盖 156 个场景，包含新增轮次取整、暂停、截止点、跨日、自然年、月份切换和长休息输入拒绝。数据库使用 `.env.local` 的 Neon 独立 schema；完整集成运行中 58 个场景通过，原长休息断言更新后补跑对应场景通过，并新增五轮列表及全年统计守恒断言，共覆盖 59 个场景。

浏览器使用 Chromium 及真实数据库，桌面和 375px 均检查页面与实际操作。功能回归覆盖首次账户／设置／目标、MCP 鉴权和读写、任务说明和资源、计时恢复、笔记、任务完成、逐轮报告、管理、补录、更正、重叠确认、取消审计与离开保存失败重试。导航回调改用当前 ref，避免从用户事件调用 Effect Event。接续提示刷新须等待保存完成后验证，不能用取消未完成保存请求的刷新代替恢复测试。

最终构建、TypeScript、ESLint、Prettier 与 `git diff --check` 均通过。浏览器共 13 个场景已覆盖并通过（包括修正后定向补跑）；其中包括计时点击到渲染的实际性能回归。独立 schema 由脚本清理，生成的 TypeScript 路径已还原。

实际截图位于 `.test-data/redesign/` 和 `.test-data/redesign-task-{desktop,mobile}.png`（测试产物，不提交）。截图来自隔离库测试数据，不能作为正式用户数据或生产上线证据。

## 色彩检查

按 sRGB 相对亮度计算：浅色主正文 14.12:1、次级正文 4.95:1、主按钮 6.49:1；深色主正文 15.97:1、次级正文 9.21:1、主按钮 8.80:1。输入边界浅色 3.12:1、深色 3.25:1。状态还通过文字、图标与 ARIA 表达。

## 范围与限制

- 时间线展示当前分页范围的观察区间；更早记录可继续分页，不加载无限历史。补录和时间更正通过记录列表查看。
- 更正后的多轮 Session 使用明确的整条更正记录展示，因为汇总时长不能反推出每轮真实分配。
- 客户端浏览器协议测试通过不等于重新验证实际外部 ChatGPT 连接；本轮没有部署。

## 侧边栏展开／收起补充验收

参考 Gemini 的桌面交互，新增顶部切换按钮；展开 216px、收起 72px，收起保留图标导航，正文同步调整。专注默认收起但可手动展开，手动选择在当前应用会话内跨路由保留；移动端保留抽屉导航。

- 本地 Chrome 实际验证足迹页展开、收起与标签恢复。
- `pnpm test:e2e tests/e2e/sidebar.spec.ts`：1 个端到端场景通过，覆盖宽度、正文位置、路由连续性、键盘 Enter、专注默认与手动切换、375px 抽屉及取消执行。
- `pnpm typecheck`、变更文件 ESLint、Prettier 与 `git diff --check` 通过。
- 截图：`.test-data/sidebar/focus-expanded.png`、`.test-data/sidebar/focus-collapsed.png`。

侧栏交互细化：收起时在同一次渲染中移除文字；顶部默认显示 AimThread 图标，悬停或键盘聚焦时替换成展开图标。侧栏 E2E 已补充文字移除、悬停切换及真实 Tab 聚焦检查，回归通过；类型检查、ESLint 与格式检查通过。
